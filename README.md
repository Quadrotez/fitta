# Fitta

Лёгкая статическая цифровая примерочная. Пользователь загружает изображения своих вещей, выбирает слои на 3D-манекене и сохраняет образы.

## Возможности

- **Локальный гардероб:** изображения и пресеты записываются в `localStorage` текущего браузера.
- **3D-просмотр:** модель можно поворачивать мышью; доступны три базовых силуэта.
- **Слои образа:** верх, низ, верхняя одежда, обувь и аксессуары.
- **Без сервера:** приложение не отправляет пользовательские изображения в API.

> Это визуальный эскиз: изображение вещи проецируется перед соответствующей зоной манекена. Точная физическая посадка, ткань и окклюзия потребуют серверной ML-модели или подготовленных 3D-ассетов.

## Локальная разработка

```bash
pnpm install
pnpm dev
```

## Проверка production-сборки через Docker

```bash
docker compose up --build
```

После сборки приложение будет доступно на `http://localhost:3000`.

## Vercel

`vercel.json` уже задаёт команду сборки и SPA rewrite. При импорте репозитория в Vercel достаточно выбрать этот проект: переменные окружения для логики приложения не нужны.

## Ограничение localStorage

Обычный лимит браузера — около 5 МБ на origin. Поэтому интерфейс ограничивает одиночный загружаемый файл 1,8 МБ. Для большей библиотеки стоит заменить хранилище на IndexedDB или S3.

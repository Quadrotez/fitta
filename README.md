# Fitta

Лёгкая статическая цифровая примерочная. Пользователь загружает изображения своих вещей, собирает слои на 2D-lookboard и сохраняет образы локально.

## Возможности

- **Локальный гардероб:** изображения и пресеты записываются в IndexedDB, с резервным режимом для браузеров, где IndexedDB недоступна.
- **2D-lookboard:** полотно можно масштабировать колёсиком или кнопками, а вещи — перемещать прямо drag-жестом.
- **Редактор слоя:** ширина и высота меняются независимо; контрольные точки включаются только для точечной деформации.
- **Слои образа:** верх, низ, верхняя одежда, обувь и аксессуары.
- **Без сервера:** приложение не отправляет пользовательские изображения в API.

> Это приватный 2D-визуальный эскиз: изображения вещей накладываются по слоям на рабочее полотно без отправки пользовательских данных на сервер.

## Локальная разработка

```bash
pnpm install
pnpm dev
```

## Проверка production-сборки через Docker

```bash
docker compose up --build
```

После сборки приложение будет доступно на `http://localhost:3000`.

## Vercel

`vercel.json` уже задаёт команду сборки и SPA rewrite. При импорте репозитория в Vercel достаточно выбрать этот проект: переменные окружения для логики приложения не нужны.

## Локальное хранилище

Основное хранилище — IndexedDB: оно рассчитано на существенно большие объёмы изображений, чем `localStorage`. Для профилей браузера, где IndexedDB запрещена, приложение использует резервное преобразование изображений в data URL и сообщает о режиме хранения в шапке.
